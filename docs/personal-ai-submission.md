# Personal AI submission draft — verification required before publication

## Positioning

CookieAI is a personal project assistant that carries useful experience between
projects. It combines persistent memory with bounded task execution, conditional
procedures, source revision checks, and inspectable evidence.

The initial workflow prepares a project handoff from selected notes. CookieAI
creates a versioned artifact and checks its structure and exact quotations.
Successful observed runs can feed its existing evidence-gated learning pipeline.
An explicitly confirmed handoff contract can then be reused when current inputs
meet its conditions. Exceptions, missing inputs, changed revisions, or revoked
access prevent automatic reuse.

The contribution is the integration of experience, applicability, verification,
and user control. We do not claim to have invented persistent agent memory or
skill reuse.

## Additions during this implementation

- Same-origin responsive product portal.
- A bounded handoff operation on the existing SQL task supervisor.
- Versioned, attributed artifacts and independent structural checks.
- Executable contracts attached to existing procedures.
- Explicit applicability/exception checks and pinned revisions.
- Namespace/source disclosure restrictions at the shared provider boundary.
- Workspace projection erasure and artifact integrity checks.
- Nebius discovery/inference configuration and preflight.
- Synthetic demo, fixture evaluation, and additional integration tests.

## Do not publish these as completed until verified

- Exact NVIDIA model ID and model license: fill from the selected live catalog.
- Nebius runtime evidence and actual usage: user deferred setup.
- Hosted demo URL and judge credentials: not created by this change.
- OpenShell/NemoClaw runtime isolation: policy template only.
- Real-phone and visual QA: browser infrastructure was unavailable.
- Sustained always-on operation and actual-host recovery drills.
- Measured same-model semantic baseline comparison.
- Public repository license and publication review.

## Video outline — target 2 minutes 40 seconds

0:00–0:20 — Explain the problem: personal assistants lose useful context and
repeat mistakes across projects. Show the selected project and approved sources.

0:20–0:50 — Approve a bounded handoff task. Show it running and open the actual
artifact with citations and verification receipt. Clearly disclose edited waits.

0:50–1:20 — In another session/project, show a confirmed skill and the conditions
that make it applicable. If using preloaded history, explicitly label it as such.
Do not claim the synthetic local demo learned a real skill.

1:20–1:45 — Show an incompatible project with a missing field or declared
exception. The assistant refuses automatic skill reuse and explains why.

1:45–2:05 — Correct a supporting source. Show the affected skill/task requiring
review; historical receipts remain historical evidence.

2:05–2:25 — Inspect disclosure policy and demonstrate that a restricted hosted
call is blocked. Explain that cloud inference transmits approved selected data.

2:25–2:40 — Show the actual Nebius/NVIDIA path and measured results ONLY after
live acceptance. State remaining limitations without implying unlimited privacy,
semantic correctness, or certified uptime.

## Submission checklist

Re-read https://nebiusglobalaihackathon.devpost.com/rules before submitting.
Provide an accessible demo/test build, public licensed source, setup instructions,
actual NVIDIA/Nebius usage evidence, a video under three minutes, and an accurate
description of improvements during the submission period. Keep synthetic demo
data separate from personal records. Publication and new paid resources need
the user's authorization.
