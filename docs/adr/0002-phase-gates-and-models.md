# Phase gates and honest model boundaries

Accepted. Phase 1 cannot establish semantic quality using hash embeddings. The deterministic hash model exists only for repeatable test execution. Production uses configurable OpenAI-compatible embedding/extraction endpoints; model ID/version/dimensions constrain recall to the correct vector space. Model proposals pass Pydantic, source, permission and business validation. No model receives SQL access. PostgreSQL acceptance is distinct from SQLite domain tests.
